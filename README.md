# BetterSelf OS

A bilingual, privacy-first priority assistant built with Next.js 16. It turns a mixed task list into one clear next move while keeping AI-training consent separate, explicit, and off by default.

## Product principles

- Arabic is fully RTL; English is fully LTR.
- Priority suggestions run locally in the prototype.
- AI training consent is never bundled with ordinary use.
- The interface favors one decision and one completion action at a time.
- A six-hover or six-tap logo Easter egg teaches concise prompting through the RCTC framework.

## Run locally

```bash
npm install
npm run dev
```

Production: [betterself-os.vercel.app](https://betterself-os.vercel.app)
